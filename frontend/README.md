# 3D-модель корпуса (TypeScript)

Живая модель 3 этажа (ИНИТ): студенты, преподаватели, расписание, события, двери.
Работает на three.js 0.147 (подключается с CDN), всё собирается в один HTML-файл.

## Команды

```bash
npm install
npm run typecheck   # только проверка типов
npm run build       # компиляция TypeScript и сборка ../campus/viewer/index.html
npm run dev         # tsc в режиме наблюдения; после изменений запустите node build.mjs
```

`npm run build` пишет два файла:

- `../campus/viewer/index.html` — страница модели для Django;
- `build/korpus-artifact.html` — тот же файл без обёртки `<html>/<head>` для артефакта claude.ai.

## Структура

| Файл | Что внутри |
|---|---|
| `src/hooks.ts` | точки расширения: `simFrame`, `evInit`, `resetDay` и др. Модули оборачивают их |
| `src/core.ts` | сцена, камера, загрузка IFC-модели, этажи, управление |
| `src/sim.ts` | сетка проходимости, поиск пути, расписание, поведение людей |
| `src/people.ts` | внешность и анимация людей (инстансинг) |
| `src/world.ts` | двор, город вокруг, погода, время суток |
| `src/events.ts` | события (линейка, комиссия, пожарная тревога…), связь с Django |
| `src/design.ts` | современный светлый интерьер 3 этажа |
| `src/brain.ts` | «умное» поведение: взгляды, диалоги, оценки, журнал, кружки, экскурсия |
| `src/doors.ts` | двери, которые открываются, когда кто-то проходит |
| `src/main.ts` | запуск |
| `types/globals.d.ts` | глобальный `THREE` (UMD), дополнения DOM |
| `types/model.d.ts` | типы модели: `NPC`, `Room`, `Door`, `SimData`… |
| `template.html` | разметка, стили, панель |
| `data/` | данные из IFC-модели: геометрия (`data.b64`) и план для симуляции (`sim.json`) |

Все файлы `src/` компилируются как обычные скрипты (без `import`) и склеиваются в один `<script>`
в порядке `ORDER` из `build.mjs`. Поэтому порядок важен: модуль, который оборачивает функцию,
должен идти после файла, где она объявлена.

## Как расширять поведение

```ts
const prevSimFrame = simFrame;
simFrame = () => { prevSimFrame(); myFeatureFrame(); };
```

## Типизация

Сейчас `strict` выключен, а у части объектов стоит `any`. Это сделано намеренно: код
переведён без изменения поведения. Типы можно ужесточать по одному файлу. Добавляйте
интерфейсы в `types/model.d.ts` и убирайте `as any` там, где тип уже известен.
