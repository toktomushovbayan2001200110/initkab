# ИНИТ: живой корпус

Живая 3D-модель 1 учебного корпуса КГУ им. И. Арабаева (Бишкек, ул. Раззакова, 51).
Третий этаж — Институт новых информационных технологий: студенты и преподаватели ходят на пары по расписанию,
общаются, получают оценки, а директор управляет всем из панели с входом по паролю.

## Что внутри

- **3D-модель** на главной странице `/`. Смотреть можно без входа, менять ничего нельзя.
- **Пульт директора** `/panel/` — только для сотрудников, вход по логину и паролю:
  - события: пожарная тревога, отключение света, Wi‑Fi, комиссия, субботник, хакатон, день открытых дверей;
  - какой сегодня день (сессия, Нооруз, Новый год, выпускной, каникулы), погода, сколько студентов пришло;
  - объявление в бегущей строке и события по расписанию;
  - студенты, группы, преподаватели: добавить, изменить, удалить, загрузить список группы целиком;
  - журнал «кто что менял».
- **Все данные** `/admin/` — стандартная админка Django для главного администратора (пользователи и пароли там же).

Люди из базы появляются в модели с настоящими именами. События из пульта за несколько секунд видят все, у кого открыта модель.

## Запуск на своём компьютере

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
python manage.py migrate
python manage.py seed            # примерные группы и студенты, можно пропустить
python manage.py createsuperuser # логин и пароль директора
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ — это модель, http://127.0.0.1:8000/panel/ — пульт.

## Кто что может

| Кто | Что может |
| --- | --- |
| Любой посетитель | смотреть модель |
| Сотрудник (галочка «Статус персонала») | пульт, события, студенты, группы, преподаватели |
| Суперпользователь | всё, плюс создавать сотрудников и менять пароли в `/admin/` |

Чтобы дать доступ коллеге: `/admin/` → Пользователи → Добавить, поставить галочку «Статус персонала».

## Ограничения модели

- До 16 групп, до 18 студентов в группе: больше не помещается в аудитории.
- Пары ведут первые 14 преподавателей из списка.
- Расписание и номера кабинетов модель пока составляет сама.
- После изменения списка людей страницу модели нужно обновить.

## Выкладка в интернет

Задайте переменные окружения и запустите через gunicorn:

```bash
export DJANGO_SECRET_KEY="длинная-случайная-строка"
export DJANGO_DEBUG=0
export DJANGO_ALLOWED_HOSTS="ваш-домен.kg"
export DJANGO_CSRF_TRUSTED_ORIGINS="https://ваш-домен.kg"
python manage.py migrate
python manage.py collectstatic --noinput
gunicorn initkab.wsgi
```

`VIEWER_REQUIRES_LOGIN=1` закрывает и саму модель за входом.

## 3D-модель (TypeScript)

Исходники модели лежат в `frontend/` и написаны на TypeScript. Сборка складывает всё в один файл
`campus/viewer/index.html`, который отдаёт Django.

```bash
cd frontend
npm install
npm run typecheck   # проверка типов
npm run build       # tsc + сборка index.html
```

Подробнее о структуре — в `frontend/README.md`.
