# Исходники 3D-модели

Готовая модель лежит одним файлом в `campus/viewer/index.html` (в него уже встроены геометрия корпуса и весь код).
Здесь лежат исходные части, из которых он собран:

| Файл | Что внутри |
| --- | --- |
| `template2.html` | страница, загрузка геометрии, камера, панели |
| `sim.js` | симуляция: расписание, навигация, потребности, задачи |
| `people.js` | фигуры людей, одежда, причёски, анимация |
| `world.js` | двор, город, погода, солнце, машины |
| `events.js` | события, праздники, звуки, прогулка от первого лица |
| `design.js` | оформление 3 этажа, мебель, лампы, пасхалки |
| `brain.js` | взгляд, приветствия, диалоги, оценки, журнал, экскурсия |

Геометрия корпуса (экспорт из ArchiCAD) в репозиторий не входит: она встроена в `index.html`.
